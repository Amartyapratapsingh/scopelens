ScopeLens lab fixture: labs-bad

This is a deliberately misconfigured nginx fixture. It serves synthetic content only and is reachable only from the isolated lab network and from loopback. It exists so that configuration controls have a vulnerable counterpart to detect.

Deliberate misconfigurations

  • No Strict-Transport-Security header (C01)
  • Session cookie with no Secure, HttpOnly or SameSite (C02)
  • No X-Content-Type-Options (C04)
  • No Content-Security-Policy or X-Frame-Options (C04)
  • No Referrer-Policy (C05)
  • Directory listing enabled at /files/ (C05)
  • Sensitive-looking files served as-is at /.env and /backup.sql (C05)
  • Verbose server tokens (C05)

Its fixed counterpart is labs-good.
